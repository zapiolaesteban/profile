03  /  Built & shipped

Things I personally built.

All my own craft — my tools, my platforms, not client deliverables. The proof that "creative leader who codes" is literal.

Live · you're using it

This site & the agent you just spoke to

Hand-built. The agent is grounded on my real history, answers by voice or text, and runs on a serverless function with my own guardrails. The medium is the proof.

Creative-AI platform

A hackathon, conceived & built end-to-end

The participant experience — agenda, timed auto-unlock mission cards, RSVP automation — plus a skill-sharing library with an AI review pipeline: contributors drop in a skill, an automated reviewer assesses it, and on approval it publishes. I'm running it in London right now.

Multi-agent org

A self-organising "Creative AI Studio"

I stood up a small AI organisation: a CEO agent that hired an HR agent, which in turn recruits specialist agents — engineers, a deep-research agent — into a team I direct. I set the goals; the agents collaborate to deliver. It even helped power the hackathon.

Multi-agent system

An "LLM Council"

Several independent models each draft a plan, get anonymised and shuffled, and a judge model merges them into one — bias-resistant decision support. I used it to pressure-test this very site's repositioning.

Personal infrastructure

A portable, version-controlled AI operating system

A full personal Claude Code setup backed by a private repo so it survives any machine: dozens of custom skills and slash-commands, MCP integrations, and clone-survivable git safety hooks with automated secret-scanning. I engineer my own tooling.

Autonomous agents

Scheduled agents that self-maintain

A weekly "doctor" agent wakes on a schedule, audits and self-maintains my whole setup, and reports back — unattended.

Executive-assistant agent

"Monday" — my daily EA agent

One terminal command: it searches my email and calendar, triages everything into P1/P2/P3, surfaces flags and who's away, and summarises threads. It drafts replies and suggests the right response — then keeps a human in the loop, popping up and opening Outlook so I decide and send. I use it daily.

Terminal tool

A terminal email-sender, with UI skins

Send polished HTML email straight from the command line — choose between several visual skins and attach files — without leaving the terminal. It also powers my event invites and RSVP auto-tracking.

Claude Code skill

An editorial deck-builder

A skill that generates polished light/dark editorial decks — multiple slide types — from a brief. Packaged and shared with colleagues.

Public app

World Clock / Time Projector

A meeting-planner across time zones. Public and linkable — a small, finished, shipped thing.
